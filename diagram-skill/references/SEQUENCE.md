# ELV System Sequence Diagrams / 弱电系统时序图集

---

## 1. 用户进门刷门禁时序

用户刷卡进门时，门禁系统完成身份认证、权限校验、电锁控制的全流程时序。

```mermaid
sequenceDiagram
    accTitle: 门禁刷卡入场时序
    accDescr: 用户刷卡后经历读卡、认证、开门、日志上传的完整流程

    participant 用户
    participant 门禁控制器
    participant 身份证阅读器
    participant 后台认证系统
    participant 电锁

    用户->>+身份证阅读器: 刷卡（感应卡/NFC）
    身份证阅读器->>+门禁控制器: 读取卡号信息
    门禁控制器->>+后台认证系统: 上传卡号请求验证
    后台认证系统->>后台认证系统: 查询数据库权限
    alt 权限验证通过
        后台认证系统-->>+门禁控制器: 验证通过，返回开门指令
        门禁控制器->>+电锁: 驱动电锁开门
        电锁-->>-门禁控制器: 开门完成
        门禁控制器-->>-后台认证系统: 开门事件上报
        后台认证系统->>后台认证系统: 记录通行日志
    else 权限验证失败
        后台认证系统-->>-门禁控制器: 验证拒绝，返回错误码
        门禁控制器-->>用户: 声光提示（刷卡失败）
    end
```

## 2. 监控视频调取时序

监控室操作员调取历史录像时，视频管理平台、NVR、摄像头之间协作完成视频回放的全流程。

```mermaid
sequenceDiagram
    accTitle: 监控视频调取时序
    accDescr: 操作员发起调取请求后，平台验证权限并指挥NVR读取视频流的全过程

    participant 监控室操作员
    participant 视频管理平台
    participant NVR录像机
    participant 摄像头

    监控室操作员->>+视频管理平台: 发起调取请求（摄像头ID+时间段）
    视频管理平台->>视频管理平台: 验证操作员权限
    视频管理平台->>+NVR录像机: 下发录像调取指令
    NVR录像机->>+摄像头: 确认摄像头在线状态
    摄像头-->>-NVR录像机: 在线应答
    NVR录像机->>NVR录像机: 从硬盘读取目标时间段视频流
    NVR录像机-->>+视频管理平台: 视频流数据包（TS/RTMP）
    视频管理平台->>视频管理平台: 流媒体转发封装
    视频管理平台-->>-监控室操作员: 推送至客户端解码播放
```

## 3. 公共广播喊话时序

值班员通过广播控制主机完成实时喊话的全流程，包含音频采集、功放放大和分区输出。

```mermaid
sequenceDiagram
    accTitle: 公共广播喊话时序
    accDescr: 值班员按下喊话键后，系统依次完成模式切换、音频采集、功放放大和分区输出

    participant 值班员
    participant 广播控制主机
    participant 功放
    participant 扬声器网络

    值班员->>+广播控制主机: 按下喊话键
    广播控制主机->>广播控制主机: 进入喊话模式，关闭背景音乐
    广播控制主机->>+功放: 实时音频流（MIC采集）
    功放->>功放: 信号放大处理
    广播控制主机->>广播控制主机: 读取分区配置（按区域选择）
    功放->>+扬声器网络: 分区音频输出
    扬声器网络-->>-功放: 输出确认
    值班员->>-广播控制主机: 喊话结束，释放按键
    广播控制主机->>广播控制主机: 恢复背景广播模式
```

## 4. 会议系统一键启动时序

用户按下"会议开始"后，中控主机依次协调投影机、矩阵、窗帘、会议终端完成会议准备。

```mermaid
sequenceDiagram
    accTitle: 会议系统一键启动时序
    accDescr: 中控主机依次下发开机指令至投影机、矩阵、窗帘和会议终端，用户确认画面就位

    participant 用户
    participant 中控主机
    participant 投影机
    participant 矩阵切换器
    participant 窗帘电机
    participant 视频会议终端

    用户->>+中控主机: 按下"会议开始"按钮
    中控主机->>+投影机: 发送开机指令（IP/串口）
    中控主机->>+矩阵切换器: 下发信号源切换指令
    中控主机->>+窗帘电机: 发送关闭指令
    投影机-->>-中控主机: 投影机开机就绪
    矩阵切换器-->>-中控主机: 信号源切换完成
    窗帘电机-->>-中控主机: 窗帘关闭到位
    中控主机->>+视频会议终端: 发起呼叫对方会场
    视频会议终端-->>-中控主机: 对方应答，链路建立
    中控主机-->>-用户: 反馈会议就绪状态
    用户->>用户: 确认画面就位，会议开始
```

## 5. 火灾报警联动时序

探测器报警后，火灾报警控制器触发消防广播、电梯迫降、防火卷帘下降和短信通知的全联动时序。

```mermaid
sequenceDiagram
    accTitle: 火灾报警联动时序
    accDescr: 探测器报警后，控制器确认区域并联动广播、电梯、卷帘，同时发送短信通知

    participant 探测器
    participant 火灾报警控制器
    participant 广播主机
    participant 电梯控制器
    participant 防火卷帘

    探测器->>+火灾报警控制器: 报警信号（感烟/感温）
    火灾报警控制器->>火灾报警控制器: 确认报警区域地址
    火灾报警控制器->>+广播主机: 切换至消防广播模式
    广播主机-->>-火灾报警控制器: 广播模式切换完成
    火灾报警控制器->>+电梯控制器: 发送消防迫降指令
    电梯控制器->>电梯控制器: 电梯强制归底开门
    电梯控制器-->>-火灾报警控制器: 迫降完成应答
    火灾报警控制器->>+防火卷帘: 下发卷帘下降指令
    防火卷帘-->>-火灾报警控制器: 卷帘下降到位
    火灾报警控制器->>火灾报警控制器: 发送短信通知消防负责人
    火灾报警控制器->>火灾报警控制器: 记录事件日志至数据库
```

## 6. 网络设备开局时序

工程师完成交换机、AC、AP开局配置的完整时序，涉及Console配置、云平台注册和SSID统一下发。

```mermaid
sequenceDiagram
    accTitle: 网络设备开局时序
    accDescr: 工程师通过Console连接交换机，逐级完成AC云平台注册和AP统一上线的全流程

    participant 工程师
    participant 配置终端
    participant 交换机
    participant AC无线控制器
    participant AP

    工程师->>+配置终端: 连接Console线
    配置终端->>+交换机: 下发基础配置（VLAN/STP/端口）
    交换机-->>-配置终端: 配置生效确认
    配置终端->>+AC无线控制器: AC基础配置
    AC无线控制器->>+AC无线控制器: 注册至云平台
    AC无线控制器-->>-配置终端: AC注册成功
    AC无线控制器->>+AP: AP发现并获取IP地址（DHCP）
    AP-->>-AC无线控制器: AP申请IP
    AC无线控制器->>AC无线控制器: 统一下发SSID/安全策略配置
    AC无线控制器->>+AP: AP上线，接收配置
    AP-->>-AC无线控制器: AP上线确认
    工程师->>+AP: 验证WIFI可用性（终端连网测试）
    AP-->>-工程师: 连网测试成功
```

## 7. 能耗数据采集时序

智能电表实时计量数据经采集器压缩加密后上传至能源管理平台，平台计算峰谷比并生成报表。

```mermaid
sequenceDiagram
    accTitle: 能耗数据采集时序
    accDescr: 电表实时计量，采集器每15分钟轮询，经4G/以太网上传至平台并生成日报月报

    participant 智能电表
    participant 数据采集器
    participant 能源管理平台
    participant 数据库

    智能电表->>智能电表: 实时计量（功率/电量/电压）
    数据采集器->>+智能电表: 每15分钟轮询读取数据
    智能电表-->>-数据采集器: 返回计量数据帧
    数据采集器->>数据采集器: 数据压缩加密（JSON+ AES）
    数据采集器->>+能源管理平台: 通过4G/以太网上传数据
    能源管理平台->>能源管理平台: 解析数据包
    能源管理平台->>+数据库: 入库存储
    数据库-->>-能源管理平台: 存储确认
    能源管理平台->>能源管理平台: 计算功率因数/峰谷比
    能源管理平台->>能源管理平台: 生成日报/月报
    能源管理平台-->>-数据采集器: 上报结果确认
```

## 8. 人脸识别速通门时序

访客到达速通门后，系统完成活体检测、人脸比对、下发开闸指令的完整通行时序。

```mermaid
sequenceDiagram
    accTitle: 人脸识别速通门时序
    accDescr: 访客到达后系统进行活体检测、抓拍比对、白名单校验，完成开闸放行

    participant 访客
    participant 人脸摄像头
    participant 人脸比对服务器
    participant 闸机控制器
    participant 门禁卡-reader

    访客->>+人脸摄像头: 走到摄像头前（触发区域检测）
    人脸摄像头->>人脸摄像头: 活体检测（防照片/视频欺骗）
    人脸摄像头->>人脸摄像头: 抓拍人脸图片（IR+RGB双摄）
    人脸摄像头->>+人脸比对服务器: 上传人脸特征图
    人脸比对服务器->>人脸比对服务器: 与白名单/人像库比对（1:N）
    alt 比对成功（阈值>0.92）
        人脸比对服务器-->>+闸机控制器: 下发开闸指令
        闸机控制器->>闸机控制器: 驱动闸机电机
        闸机控制器-->>-访客: 闸机开门放行
        人脸比对服务器->>人脸比对服务器: 通行记录上传（时间+照片）
    else 比对失败
        人脸比对服务器-->>-人脸摄像头: 返回比对失败
        人脸摄像头->>人脸摄像头: 提示重新识别/改用刷卡
        访客->>+门禁卡-reader: 改用门禁卡刷卡
        门禁卡-reader->>门禁卡-reader: 刷卡认证（进入门禁刷卡流程）
    end
```
