# 其他图表示例 (Other Diagram Examples)

## 类图 (Class Diagram) - 弱电设备管理

类图展示弱电系统中各类设备的继承关系，包括门禁、监控、网络设备的共有属性和各自特有的行为。

```mermaid
classDiagram
    accTitle: 弱电设备类图
    accDescr: 展示设备基类与门禁、监控、网络设备子类的继承关系
    
    class 设备 {
        +int 设备ID
        +string 设备名称
        +string 设备类型
        +string 安装位置
        +date 上线日期
        +获取设备信息()
        +更新状态()
    }
    class 门禁设备 {
        +string 卡号规则
        +int 权限级别
        +验证权限()
        +开门()
    }
    class 监控设备 {
        +string 摄像头型号
        +string IP地址
        +int 分辨率
        +获取视频流()
        +云台控制()
    }
    class 网络设备 {
        +string 设备型号
        +int 端口数
        +string 管理IP
        +配置端口()
        +查看状态()
    }
    
    设备 <|-- 门禁设备 : 继承
    设备 <|-- 监控设备 : 继承
    设备 <|-- 网络设备 : 继承
    网络设备 o-- 网络设备 : 组成网络拓扑
```

## ER 图 (ER Diagram) - 项目管理

ER 图展示弱电项目管理系统中的核心实体及其关联关系，包括项目、合同、设备清单和施工人员。

```mermaid
erDiagram
    accTitle: 项目管理 ER 图
    accDescr: 展示项目、合同、设备清单和施工人员之间的关联关系
    
    项目 {
        int id PK
        string 项目名称
        string 项目类型
        date 开始日期
        date 结束日期
        string 状态
    }
    合同 {
        int id PK
        int 项目ID FK
        string 合同编号
        decimal 合同金额
        date 签订日期
    }
    设备清单 {
        int id PK
        int 项目ID FK
        string 设备名称
        string 规格型号
        int 数量
    }
    施工人员 {
        int id PK
        string 姓名
        string 工种
        string 联系电话
    }
    
    项目 ||--o{ 合同 : 签订
    项目 ||--o{ 设备清单 : 包含
    项目 ||--o{ 施工人员 : 分配
```

## 状态图 (State Diagram) - 故障处理状态机

状态图描述弱电设备故障从发现到解决的完整生命周期，包含待外协处理和任务退回等分支场景。

```mermaid
stateDiagram
    accTitle: 故障处理状态机
    accDescr: 展示故障从待处理到已关闭的完整生命周期，包括外协和复发分支
    
    [*] --> 待处理
    待处理 --> 处理中 : 接受任务
    处理中 --> 处理中 : 排查问题
    处理中 --> 已解决 : 问题修复
    处理中 --> 待外协 : 需要外部支援
    已解决 --> 已关闭 : 验证通过
    已关闭 --> [*]
    待外协 --> 处理中 : 外协完成
    处理中 --> 待处理 : 任务退回
    已解决 --> 处理中 : 复发
```

## 状态图 - 门禁开关状态

状态图描述门禁系统的刷卡验证流程及消防强开场景。

```mermaid
stateDiagram
    accTitle: 门禁开关状态图
    accDescr: 展示门禁从刷卡验证到开门的完整状态转换，含消防强制开门分支
    
    [*] --> 门关闭
    门关闭 --> 刷卡验证 : 用户刷卡
    刷卡验证 --> 验证通过 : 卡号有效
    刷卡验证 --> 验证拒绝 : 卡号无效/无权限
    验证通过 --> 门打开 : 继电器动作
    门打开 --> 门关闭 : 开门超时(10s)
    验证拒绝 --> 门关闭 : 等待下次刷卡
    门关闭 --> 消防强制开门 : 火灾报警信号
    消防强制开门 --> 门打开 : 强制输出
    门打开 --> 门关闭 : 复位
```
