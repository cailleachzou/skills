# cli — 本机 CLI 工具统一入口

本技能是一个**路由器**，本身不执行任何操作。它只做一件事：
把请求分发到 `sub-skills/` 下的 4 个子技能说明书。

## 工具索引

| 子技能 | 触发词 | 一句话 |
|---|---|---|
| `ffmpeg` | 转码、剪辑、抽帧、压制、批量处理音视频、查看媒体编码信息 | 调用 PATH 上的裸 ffmpeg / ffprobe（本机无封装 CLI）|
| `ncm-dump` | ncm、网易云、加密音乐、mp3、flac | 解密 .ncm → 通用 mp3/flac |
| `pdf2zh` | PDF 翻译、论文翻译、保留排版、双栏对照 | PDFMathTranslate，默认本地 2B 模型 |
| `tyc-it` | 查公司、尽调、股权、关联关系、司法风险 | 天眼查 CLI「天眼一下」 |

## 分发规则

按以下顺序判断，命中即停：

1. **带参数调用**（`/cli <工具名>`）

   本次调用传入的工具名参数是：「`$tool`」

   - 上面引号内是上表 4 个合法值之一 → 直接 `Read sub-skills/<该值>/SKILL.md`（路径相对本技能目录），按它执行
   - 上面引号内为**空** → 跳过本规则：本次是显式 `/cli`（无参数）→ 看规则 2；是自然语言自动触发 → 看规则 3
   - 上面引号内有值但不属于那 4 个 → 先按规则 3 的「触发词」列匹配；仍不命中，才列出 4 个合法值，**不猜、不兜底、不改用别的工具**
2. **无参数调用**（`/cli`）→ 列出上表 4 行，问用户要哪一个
3. **自然语言**（自动触发）→ 用上表「触发词」列匹配
   - 命中 → `Read sub-skills/<name>/SKILL.md`（路径相对本技能目录），按它执行
   - 未命中 → 见「认输规则」

## 认输规则

上表触发词全不命中时，**明说**「这不在本路由器的 4 个工具范围内」，
并列出 4 个工具名。**不调任何子技能，不试图用别的工具凑答案。**

本路由器只覆盖这 4 个 CLI。其他能力（文档解析、CAD、Office、知识图谱等）
不在范围内，不要假装路由过去。

## 已知问题（子技能内容，尚未修复）

以下是四个子技能**既有**的内容缺陷，2026-09-13 验证时实测发现，**非本次路由器迁移引入**
（`git mv` 的 rename 记录证明迁移未改动任何子技能内容）。路由器本身经测无缺陷。
修法涉及产品取舍，留待单独处理：

- **`ffmpeg`** — `sub-skills/ffmpeg/SKILL.md` 描述的是一个**本机并未安装**的 Python 封装 CLI
  （`transcode run` / `preset list` / `session save` / `~/.cli-anything-ffmpeg/`）。本机 PATH 上
  只有裸 ffmpeg 9.0.1。**照该文档执行会失败。** 另注：`ffmpeg info status` 不会报错
  （裸 ffmpeg 把 `info` 当作输入文件），退出码 0——靠「命令是否报错」判断工具是否存在会误判。
- **`ncm-dump`** — 内嵌脚本成功写出产物后，末行中文 `print` 在 Windows cp1252 控制台抛
  `UnicodeEncodeError`，**退出码 1**，调用方会误判为失败。加 `PYTHONIOENCODING=utf-8` 可绕过。
  另：`META_KEY` 解不出元数据（歌名/封面缺失，音频不受影响）。
- **`pdf2zh`** — 文档称缓存位于 `%TEMP%\cache\`，实测为 `~/.cache/pdf2zh/cache.v1.db`；
  未提中文文件名在 cp1252 下的崩溃；未提示 MiniCPM5-2B 是推理模型，在 pdf2zh 的固定参数下
  `content` 可能返回空串。
- **`tyc-it`** — 全文 315 行未提 `tyc` CLI **需要凭据**（`tyc init --authorization <KEY>` 或
  `tyc login`）。未配置凭据时，读完整个文件才会在首次真实调用处失败。

## 维护规则

> ⚠️ 两条硬规则。2026-08-06 拆除旧路由器 `cli-anything` 的直接原因就是没遵守第二条。

**新增 CLI**（两步，零代码）：

1. 建 `sub-skills/<name>/SKILL.md`（+ 可选 `scripts/`、`references/`）
2. 在上方「工具索引」表加一行

**停用 CLI**：

1. 把 `sub-skills/<name>/` **整个目录移出**
2. **删掉**「工具索引」表对应行

**禁止**留 `sub-skills/<name>.disabled/` 这类残留——索引与目录必须严格一致。
若忘记加索引行，可用 `LS sub-skills/` 兜底发现。

## 子技能说明在哪

每个子技能的完整说明书在 `sub-skills/<name>/SKILL.md`，**按需 Read，不要预先全读**
（会浪费上下文）。本文件不含任何具体命令参数，参数一律看子技能说明书。
