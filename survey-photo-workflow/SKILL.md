# 勘察照片整理工作流

将现场拍摄的勘察照片通过 AI 理解后重命名、归档到项目标准文件夹，并辅助编制勘察报告。

## 触发场景

- "勘察照片整理"
- "照片归档到勘察文件夹"
- "编制勘察报告"
- "帮我把现场照片整理一下然后出勘察报告"
- 用户提供照片文件夹 + 提到勘察/现场

## 与 batch-image-renamer 的分工

| 步骤 | 负责 |
|------|------|
| AI 理解照片 → 重命名 | **batch-image-renamer**（委托 subagent） |
| 重命名后照片归档到项目勘察文件夹 | **本技能** |
| 基于照片内容编制勘察报告 | **本技能** |

## 工作流程

### Phase 1: 照片重命名

委托 `batch-image-renamer` 技能处理：

```
使用 batch-image-renamer 技能，处理文件夹: {photo_folder}
```

该技能会：
1. 扫描图片文件
2. AI 多模态理解每张照片
3. 按 `Tendo - <描述>-NNN.<ext>` 格式重命名

### Phase 2: 归档到勘察文件夹

重命名完成后，将照片移动到项目的标准勘察文件夹：

**目标路径**：
```
{Project Dir}/Tendo - 03_资料 Technical Archive/勘察照片/
```

**操作**：
1. 确认项目目录（从上下文或询问用户）
2. 创建目标文件夹（如不存在）
3. 移动所有重命名后的照片到目标文件夹
4. 生成照片索引清单（Markdown 格式）：

```markdown
# 勘察照片索引

**项目**: {Project Name}
**日期**: {YYYY-MM-DD}
**总数**: N 张

| 序号 | 文件名 | 描述 |
|------|--------|------|
| 1 | Tendo - 配线架已安装-001.jpg | E座21F机房A配线架 |
| 2 | Tendo - 旧设备待拆除-002.jpg | E座21F机房B旧设备 |
```

### Phase 3: 编制勘察报告（可选）

如果用户需要勘察报告：

1. 读取照片索引和 AI 理解结果
2. 结合项目上下文（如有），生成结构化勘察报告：

```markdown
# {Project Name} 现场勘察报告

**日期**: YYYY-MM-DD
**勘察人**: {Name}
**项目地点**: {Address}

## 1. 项目概况
{项目背景和本次勘察目的}

## 2. 现场条件

### 2.1 {区域1}
- 现状描述（基于照片理解）
- 现有设备清单
- 布线情况

### 2.2 {区域2}
{...}

## 3. 发现的问题与风险
- [ ] {问题1}: {描述}
- [ ] {问题2}: {描述}

## 4. 建议措施
1. {建议1}
2. {建议2}

## 5. 照片附件
详见勘察照片文件夹。
```

3. 保存到项目文件夹：
   ```
   {Project Dir}/Tendo - 03_资料 Technical Archive/勘察报告/
   ```
4. 可选：通过 `md2pdf` 转为带 Tendo 品牌页眉的 PDF

## 依赖技能/工具

| 依赖 | 用途 |
|------|------|
| batch-image-renamer | AI照片理解 + 重命名 |
| md2pdf (tendo-brand) | 勘察报告转 PDF（可选） |
